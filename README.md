"Care Matters in Human-Ecological Infrastructures" is a transdisciplinary [autumn school led by metaLAB (at) Basel](https://metalab.harvard.edu/e/caremattersbasel/) and co-produced with the metaLAB community (Harvard, Berlin, Basel), taking place during Mesh Festival Basel, October 14- 17, 2026.

This repository holds the setup guide for the autumn schools local data collection and analysis computer. 

## Overview

- [setup-guide.md](./setup-guide.md): A guide to setup the local machine
- [data-preparation.py](./data-preparation.py): A script to turn folders of data into tabular structure
- [data-example](./data-example/): Example data for how the sessions data might look like
- [export](./export/): Were CSV files generated out of the folder data are exported to
- [data-analysis.ipynb](./data-analysis.ipynb): A notebook for data exploration
- [sketches](./sketches): A place to collect visual engagements with the data
